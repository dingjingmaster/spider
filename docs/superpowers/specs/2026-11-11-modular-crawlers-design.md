# 模块化爬虫与按爬虫串行调度

用户要求按功能分目录，每个模块只通过一对公共 .h/.c 提供功能；新增 src/spiders 实现统一爬虫接口。调度器多线程运行不同爬虫，同一爬虫所有操作在同一工作线程顺序执行。用户已授权按讨论的规范重新实现，在当前工作区修改，不提交或推送。

## 模块与接口

- crawler/crawler.h,c：注册 C 爬虫定义、校验配置、运行上下文、协作取消和生命周期；不暴露全局 App。
- download/download.h,c：HTTP 响应、Cookie 会话、文件下载与发布。内部封装 libcurl；通过回调登记文件，不依赖 storage/web/scheduler。
- rule/rule.h,c：公共规则校验、模板与旧定义升级，辅助实现放在 private。
- parser/parser.h,c：HTML CSS、JSON Pointer、字段转换；无网络和数据库操作。
- storage/storage.h,c：不透明 Store、配置/运行/文件/会话/工作流检查点的语义接口。SQLite、SQL、互斥锁仅在内部。旧数据库版本和规则快照保持兼容。
- scheduler/scheduler.h,c：定时控制、固定线程池、任务领取、手动启动/取消。工作线程拥有一次完整运行，取消后保留爬虫占用直到回调退出。同一配置 ID 最多一个活动运行，定时重复触发合并。
- status/status.h,c：读取持久状态、汇总进度、事件和步骤；生命周期状态以 storage 为准。
- web/web.h,c：配置/API/网页，通过模块接口操作，不直接访问 SQL 或数据库结构。
- spiders/spiders.h,c：统一注册入口。spiders/workflow 是现有 JSON 工作流实现，所有 foreach/parallel 分支串行推进，保留汇合、重试、预览和重启恢复。

模块允许 private/ 下私有辅助文件，但跨模块仅引用公共头文件。common/model 是小型通用类型和工具。运行上下文有独立会话、配置快照、存储/下载句柄、取消与状态回调，不共享站点可变全局变量。新增网站实现注册定义，不修改调度器。

## 线程与持久化

独立调度控制线程检查间隔计划；N 个工作线程分别执行一个爬虫运行。所有创建任务的入口都经过 scheduler，同一爬虫按 SQLite 配置 ID 识别，不按站点域名识别。调度器占用表覆盖运行结束到回调清理的时间窗口。网络、解析与文件 IO 不持有调度/数据库锁。停止服务唤醒工作线程，取消传输并等待线程退出后销毁依赖。

工作流逐运行初始化与领取步骤，不能领取其他运行的步骤。数据库提交的步骤保持幂等；重启后恢复检查点。非幂等 POST 保留原有不自动重放约束。取消立即持久化，实际线程退出前拒绝重新启动。同一站点不同爬虫的域名限速不在本次重构新增。

## 范围和取舍

采用完整运行占用线程，结构清晰且严格保证线程内串行；重试等待会占用该工作线程。放弃按步骤跨线程轮转方案，避免把可恢复 C 调用栈改成复杂状态机。保留现有 JSON 规则作为默认实现，兼容 API、数据库与网页；不新增未知网站规则、小说合并、跨次资源去重或 DRM/浏览器功能。

## 验证

原 12 项测试；新增真实 HTTP 并发测试证明不同爬虫重叠而同一爬虫不重叠、重复启动/定时不堆积；原生 C 爬虫证明注册与串行、取消退出期间防重；数据库恢复、预览会话、文件发布回滚和导出继续通过。Release 和 ASan/UBSan 各运行完整测试，静态依赖检查确认 SQL 不越界。
